# C5: KYC Fraud Detection System

This repo contains a system for the eSewa hackathon.

Detects forged documents, duplicate identities, and suspicious onboarding behavior during digital KYC.

## Project Description

eKS (eSewa KYC Shield) runs document forensics, identity deduplication, and behavioral analytics in parallel to produce a single risk score per submission. Based on the score, submissions are auto-approved, flagged for review, or rejected.
